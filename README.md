# Rajeshwari M B — Data Analyst Portfolio

Personal portfolio website showcasing my projects, skills, internship experience and certifications.

🔗 **Live site:** https://rajeshwari-40.github.io/portfolio/

## About

Fresher B.E. Computer Science graduate (2026) with hands-on experience in Python, SQL, Excel, Power BI and NLP-based projects. This site showcases my data analytics work, internships and certifications.

## Features

- **Hero section** with a typing SQL/Python query line, profile photo and a **Play Reel** card that opens an intro video
- **Video popup** with tabs to switch between multiple videos
- **Flip ID card** in the About section: click the photo to see contact details and a QR code to my LinkedIn
- **Dark / light mode** toggle (remembers your choice)
- **Dashboard viewer**: click a Power BI dashboard to open it full size
- **Resume download** button
- Scroll animations and a fully **responsive** layout for desktop, tablet and mobile
